# 🚀 坦克大战 · Tank Battle

一个纯 HTML + Canvas 实现的经典《坦克大战》网页游戏，无需任何依赖，打开即玩。

## ✨ 功能特性

- 🕹️ **经典玩法**：控制坦克移动射击，消灭所有敌方坦克即可过关
- 🦅 **保卫基地**：守护地图底部的老鹰基地，一旦被摧毁游戏结束
- 🧱 **多样地形**：可摧毁的砖墙、不可摧毁的钢墙、可穿越的水面、可藏身的草丛
- 🤖 **敌军 AI**：敌方坦克会追踪、游走并开火
- 🎁 **道具系统**：随机掉落护盾（S）与生命（+1）
- 📈 **关卡递进**：4 张地图循环，敌军数量与难度随关卡提升
- 🔊 **音效**：Web Audio API 实时合成射击/爆炸/道具音效
- 💾 **最高分**：本地存储记录最高分

## 🎮 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 | P |
| 开始 / 重新开始 | Enter |

## 🚀 运行方式

直接双击打开 `index.html`，或在任意静态服务器下运行：

```bash
# 使用 Python
python3 -m http.server 8000

# 然后访问
http://localhost:8000
```

也可以通过 GitHub Pages 在线游玩（本仓库已配置为可直接部署）。

## 🛠️ 技术实现

- 纯原生 JavaScript，无第三方库
- Canvas 2D 渲染，`requestAnimationFrame` 游戏循环
- 基于网格的地图与碰撞检测
- 面向对象的坦克/子弹/粒子系统
